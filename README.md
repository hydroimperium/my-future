# 🌿 Моё будущее (My Future MVP)

Веб-сервис превентивной оценки здоровья и прогнозирования ожидаемой продолжительности жизни на основе демографической статистики, клинических факторов риска и ИИ-аналитики.

## ⚙️ Принцип работы
Система разделяет математические расчёты и генерацию текста, исключая галлюцинации языковой модели в цифрах:
1. **Сбор данных:** Пользователь заполняет анкету образа жизни и региона проживания. Опционально прикрепляет файл лабораторных анализов (`.pdf`, `.docx`, `.txt`) и вводит индивидуальные особенности здоровья свободным текстом.
2. **Агентный поиск и парсинг:** Нестандартные медицинские сведения и редкие биомаркеры из файлов верифицируются по медицинским источникам в сети и переводятся в стандартизированные поправки риска.
3. **Актуарно-клиническое ядро:** Движок рассчитывает текущий прогноз продолжительности жизни, биологический возраст, сердечно-сосудистые индексы и потенциал при коррекции управляемых привычек с защитой от двойного счёта факторов.
4. **Доказательная база (RAG) и ИИ-отчёт:** Под выявленные точки роста подбираются научные рекомендации, на базе которых LLM формирует структурированный аналитический отчёт простым языком.

## 📁 Архитектура проекта (`backend/`)
* `main.py` — сервер FastAPI, маршрутизация API и раздача веб-интерфейса.
* `schemas.py` — Pydantic-модели входных данных и региональные демографические профили.
* `clinical_scores.py` — расчёт базового дожития, сосудистых шкал и биологического возраста.
* `calculator.py` — главный оркестратор расчёта факторов риска, потенциала и перекрёстной верификации данных.
* `lab_parser.py` — модуль извлечения и кластерного анализа лабораторных бланков (`.pdf`, `.docx`).
* `ai_service.py` — интеграция с LLM API, модуль веб-поиска медицинских данных и пост-верификация отчёта.
* `knowledge_base.py` — локальная база доказательных медицинских фактов и рекомендаций.
* `database.py` — сохранение истории расчётов в SQLite.
* `index.html` — клиентский веб-интерфейс.

## 🚀 Локальный запуск

1. Установить зависимости:
   ```bash
   pip install -r requirements.txt

2. Создать файл .env в папке backend/:
    ```bash
    LLM_API_KEY=ваш_ключ_api
    LLM_BASE_URL=[https://generativelanguage.googleapis.com/v1beta/openai/](https://generativelanguage.googleapis.com/v1beta/openai/)
    LLM_MODEL=gemini-3.5-flash-lite

3. Запустить сервер:
    ```bash
    python -m uvicorn main:app --reload    

4. Открыть в браузере: http://127.0.0.1:8000/
